The work: a pure module over the compiler parse that turns canvas edits into minimal .case.md text patches. API sketch: patchField(text, blockId, field, value), listFieldAdd/Remove(text, blockId, field, entry) for Supports/Needs/Opens/Gate lines, appendBlock(text, kind, template), removeBlock(text, blockId). Uses the parser's block/field spans; never reformats untouched lines.

Why it blocks: every canvas edit verb (inspector forms, edge drag, node lifecycle) writes through this layer. DD-003: markup stays the store; the canvas edits it by patch.

Acceptance: unit tests prove (a) a no-op patch is byte-identical, (b) patch→compile equals editing the field by hand, (c) list ops preserve line order and formatting, (d) patches compose. Pure ESM like src/compiler — importable by node tests and Vite.
