SB-048 feel-gate finding: every canvas node carries too much metadata — label, summary, domain, category, supports, discuss, peek, meta, title, and more. Terje: 'this can't be strictly necessary.'

The decision only Terje can make: for each node kind, which fields must the node FACE show, which fold behind the inspector, and which are candidates to drop from the markup entirely? The split matters — a field can be load-bearing for the sim yet still hidden on the canvas.

Why it blocks: node size drives how the whole board reads. The canvas-layout probe should run on culled nodes, or its verdict measures the wrong thing.
