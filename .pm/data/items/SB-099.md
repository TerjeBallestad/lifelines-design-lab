      **Selection path:** exact pool `char|key_type|key` first, else wildcard `char|key_type|*`. Caveat: fallback is per-pool-EXISTENCE, not per-availability — an exact pool whose lines are all on cooldown returns nothing and never reaches `*`.

      | key type | fires when | notes |
      |---|---|---|
      | need/<NeedId> | a need crosses a threshold DOWNWARD (crossed_below only) | keys case-sensitive: Hunger/Bladder/Energy/Social/Security |
      | activity/<Name> | a character STARTS that activity | key = raw activity display name, case-sensitive; case mismatch silently degrades to activity/* |
      | aversion/<key> | activity ABANDONED (key = activity name) OR object claim FAILED (key = object_type) | two disjoint key sources share one namespace, no schema distinction |
      | relational/<visitor> | doorbell_rang, visitor_entered_room, visitor_left_room | broadcast to every resident; keys lowercase canonical (frank, grete); enter+leave share the pool so cooldown usually eats the second |
      | want/*, dagsform/* | idle heartbeat every 90 sim min (thought_heartbeat_minutes), merged into ONE candidate array | **WILDCARD ONLY — an authored want/Read or dagsform/tired loads but NEVER fires** (heartbeat hardcodes KEY_ANY; documented IOU) |
      | ambient/* | NOT in the trigger map — bubble layer loads <char>_ambient_any.tres directly, fires on a 15-25 WALL-second timer when idle | lines are ICON KEYS, not prose; never reaches TANKER; unseeded randi() = non-deterministic |
