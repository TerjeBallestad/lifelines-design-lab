SB-040 ruling 2 (script half): 'an unknown id in Supports/Opens/a weave jump becomes a wired stub' — the Twine/Yarn/Ink consensus. Today the compiler emits stub-unresolved-id diagnostics but buildGraph drops edges whose endpoint never became a node, so a stub named in the script lens is INVISIBLE on the canvas until its block exists. Render stubs as ghost nodes (dashed border, 'stub — no definition' sub) carrying their wired edges; clicking one offers 'create the block' (reuse the SB-042 create machinery).

Why it blocks: without this, 'script creates by naming' only half-works on the hybrid page — naming makes a stub, but only the script lens can see it (found while building SB-041's evidence: beat 3 had to name a full block instead).
