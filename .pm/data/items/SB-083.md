## What
Make the two existing lens pages load and save any `.case.md` under `content/cases/`, so the Playtest lens inherits a case-agnostic seam instead of inventing one. The full site inventory and the recommended shape are in the SB-059 resolution comment — read it first, it names all 13 call sites.

The shape, in short:
1. New shared module owning the active case: path, text, and the four localStorage key builders (`draftKey`/`posKey`/`modeKey`/`pinKey`). It replaces the duplicated `DRAFT_KEY` literal in prototypes/canvas/model.ts:29 and prototypes/script-editor/main.ts:41.
2. Discovery via `import.meta.glob('/content/cases/**/*.case.md', { query: '?raw', import: 'default', eager: true })` — verified against the installed vite 8.0.14. Eager keeps the case in the module graph, so the current external-edit reload behavior survives; a `fetch()` loader would lose it.
3. `?case=<path>` URL param carries the active case across the two lens cross-links and across reload.
4. `/__save-case?path=<relpath>` — vite.config.ts resolves the target, rejects anything outside `content/cases/` or not ending in `.case.md`, and keeps `lastSaved` in a per-path Map so the self-write reload suppression stays correct per file.
5. The hard-coded `tiny-olsen.case.md` file label in both index.html files becomes a select over the glob keys, labelled with the compiled `slice.title`.

## Why it blocks
The map's ruling is case-agnostic from day one. This is that ruling made concrete.

6. Add a second case as a stub, in scope here (Terje, 2026-08-09). Only one case exists on disk today, so the picker is not verifiable as a picker without it. Keep it minimal — a `# Case:` header with an id and a title, plus one document and one fact, so it compiles clean and renders something. It exists to prove the seam switches, not to be played. Give it its own directory under `content/cases/` so the glob pattern is exercised across directories, not just filenames.

## Notes
No compiler change is needed — src/compiler is already case-agnostic, and the case names itself in its `# Case:` header.
