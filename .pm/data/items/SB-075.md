The lens shell in prototypes/canvas is now the app shell: SPRINT-002 mounts a third lens (Playtest) on it and SPRINT-003 adds sub-views. Two structural debts block that growth.

1. Typecheck coverage: prototypes/canvas and prototypes/script-editor sit outside the tsconfig. Vite transpiles them in dev only, so 'npm run lint' never typechecks the editor. Move them under a tsconfig project so lint covers them.

2. main.ts split: prototypes/canvas/main.ts is ~1850 lines and absorbs every feature. Split along the existing seams — lens shell / save-recompile loop / inspector / edge authoring / draft persistence — so SB-060 and SB-061 mount the Playtest lens against a module boundary, not a monolith.

Out of scope: any framework adoption (DD-003 stands — the probe code is the substrate), behavior changes (probe-smoke.test.ts is the parity bar), the draft staleness guard (SB-074).
