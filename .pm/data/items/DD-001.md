Context: markup 0.2 must cover calls, frank_chat, recipes, frank_proposals — sections 0.1 never emitted. The 0.2 weave (§8) is an ink-style text-choice menu, but the shipped runtime removed ask buttons in Round 3: a choice is a Funn card the player drops (call exchanges keyed by card_id, chat threads keyed by one required fact).

Decision: hybrid. calls and frank_chat are # Conversation: weave blocks where a top-level branch is CARD-KEYED (* f_x: = the player plays card f_x), preserving indented replies, guards, speaker tags, liftable spans. recipes, frank_proposals, and the two pack-level pair reject lines stay declarative blocks.

Why: flow constructs (replies, follow-ups, fallback) have a clean 1:1 runtime target and earn weave. Pair crafting is arity-2 unordered matching with irreversible card consumption — data, not flow. Faking a menu with * sigils would misdescribe the game.

Alternatives rejected: all-declarative (closest to JSON but loses replies/guards), all-weave (runtime plays almost none of §8).
