DD-010 dissolves the # Visit: oppdrag_* blocks: an Oppdrag becomes a set of goals, each one scene in the SB-107 stage syntax plus three new authored fields - requirements (conditions to attempt), cost (visit time), yield (facts/unlocks). This probe picks the surface markup for those fields, the same way SB-107 picked the stage syntax.

The question: what does a goal block look like so Terje can write one without a manual? Sub-questions: how requirements name presence/facts/denial facts, whether cost is authored or derived from the scene, how yield relates to the existing fact: spans, and what of the Offer/Unlocks fields on today's Oppdrag survives at which tier.

Why it blocks: the compiler emitters and the editor Visit view can not extend to goals before the syntax is ruled. Least probe: extend prototypes/visit-syntax/ (SB-107) with a goal wrapper; Terje rewrites oppdrag_alene as 2-3 goals.
