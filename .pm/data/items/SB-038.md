      Findings — canvas UX survey (three parallel web agents, 2026-08-06). Per tool, the moves that make authoring fluid, then the steal shortlist.

      **Twine**
      1. Write-a-link-and-the-node-exists: type `[[Go to the cellar]]` in a passage; if no such passage exists, Twine creates it on the map near the linker, already wired. The graph grows behind you while you keep typing.
      2. Text is the only source of truth: there are no edge tools at all. Structure edits and prose edits are the same gesture, so "back up and rewrite" restructures the graph for free. Broken links get an exclamation emblem on the passage.
      3. P-key fuzzy jump over names and body text; picking a result pans the map there. Keeps 100 passages navigable with no hierarchy. Zoom is a detail dial: zoomed out, passages shrink to name-only chips.

      **Yarn Spinner (VS Code graph view)**
      1. Graph and text are two lenses on one file: double-click a node to land in its text; write `<<jump NewNode>>` in text and the edge (plus a missing-node diagnostic) appears in the graph.
      2. Drag from a node's handle onto empty space creates a new, already-connected node that opens in inline rename mode — lift-and-connect in one gesture, no dialog.
      3. Header-as-metadata grouping (`cluster:`, `color:`, positions in node headers) — organization survives round-trips through plain text. Yarn Classic/YarnLoom/Crochet all auto-create the target of an unresolved jump (Twine's move, ported).

      **Ink (Inky / inklewriter)**
      1. Replay-to-cursor: Inky recompiles continuously and fast-forwards the play pane through your previous choices. Writing and testing are one activity.
      2. Diverts are hyperlinks and TODOs are a worklist: name a knot that does not exist yet, keep writing, and the issue browser holds the stub for later.
      3. inklewriter's stub loop: writing a choice creates its destination; unwritten branches become "loose ends" with a visible counter, searchable, with rewind to write the other branch. Emily Short: it "makes you feel reasonably safe about just sitting down and going for it" — but the map view tangles past moderate size.

      **ChatMapper**
      1. Child-from-node, form-first: a plus button on any node creates a connected child and immediately prompts for its text — you never place-then-wire. Shift-click makes a sibling. Deleting a node re-links across the gap.
      2. Tree discipline at scale: one primary link per node, cross-links drawn thin, per-node collapse, overview window, arrow-key navigation.

      **Drafft**
      1. Node/script split: nodes hold structure; long-form writing happens in a linked text editor, not in canvas boxes.
      2. Otherwise standard React Flow ergonomics (drag-from-port, context menu, snap, undo). Thin documentation; least to steal here.

      **Unreal Blueprints** (Terje's reference workflow)
      1. Drag-wire-to-empty-space spawns a pre-filtered, pre-connected node: release on empty canvas → context menu with search focused, filtered to what that pin accepts → Enter → node lands wired. Zero clicks between "I need a thing here" and "it exists, connected". Chord keys (B+click etc.) place high-frequency nodes with no menu.
      2. Wires are directly editable objects: double-click adds a reroute elbow, alt-click breaks, ctrl-drag moves all wires to another pin or re-summons the menu on empty space.
      3. Comment boxes are the zoom-out map: titles scale UP as you zoom out, so a distant graph reads as a labeled block diagram. Boxes move their contents. Bookmarks list comments as jump targets — a table of contents.
      4. Collapse tames scale: collapse-to-node/function/macro turns crossing wires into pins automatically; double-click enters.
      5. One-key tidying: Q straightens wires, Shift+WASD aligns. Constant cheap grooming instead of dreaded cleanups.

      **Steal shortlist for Kildeverket (feeds the SB-040 grill)**
      1. Write-creates-structure: naming a not-yet-existing id in a field (Supports, Opens, needs) should create the stub node, wired — the Twine/Yarn/inklewriter consensus move, and the direct answer to "form-filling on a static graph".
      2. Loose-end counter: stubs and empty required fields as a visible, jumpable worklist (we already have diagnostics — surface them as the worklist).
      3. Drag-wire-to-empty-space → filtered create menu → node lands connected with focus in its first field (Blueprints + Yarn). Our RELATION table is exactly the "context-sensitive filter".
      4. Comment boxes with zoom-up titles as the 80+ node overview, plus fuzzy jump (P/Ctrl-F) over ids, titles, and field text.
      5. Two lenses on one file: canvas and script editor over the same markup with jump-to-block both ways — we are uniquely close to this already (markup is the store, DD-003).
      6. Common thread across every tool that feels good: each frequent intent is a single gesture at the point of attention, and focus lands where typing is next needed. No round-trips through a palette or form.

Question: what do working node editors do that our canvas does not — node creation flow (where does a new node land, what has focus), overview and navigation at 80+ nodes (collapse, grouping, zoom semantics, minimap), edge affordances, and above all support for fluid, linear-ish authoring (write → lift → connect → back up) rather than form-filling on a static graph?

Scope: Yarn Spinner, Twine, Ink (inky/inklewriter), Drafft, ChatMapper — and Unreal Blueprints, which Terje has used a lot and whose workflow he likes (comment boxes, reroute, collapse-to-function, context-sensitive palette from a dragged wire). SB-027 already surveyed these tools' features and file formats — do not repeat that. This ticket is canvas UX only.

Why it blocks: SB-036's probe verdict (canvas is 'how the computer likes it, not how the human likes it') means the authoring model must be redesigned before more canvas work. This research feeds the authoring-model grill.

Deliverable: findings comment — per tool, the 2-3 moves that make authoring feel fluid, and a shortlist of mechanisms worth stealing for Kildeverket.
