      RESOLUTION (wayfinder research session, 2026-08-09). Read against the committed tree at 2dd4af9 — SB-055's files are committed and the working tree is clean, so the pre-verdict caveat on the earlier comment is discharged.

      THE HEADLINE: the seam is not two lenses, it is three. prototypes/script-editor/main.ts already carries its own renderFactCard / renderDocPreview / wireDocFrame / openLightbox (lines ~205–330), and canvas/preview.ts is a port of them. wireDocFrame is byte-for-byte identical apart from the jump callback. Extracting pays off the duplication that exists today, not only the copy SB-061 would add.

      EXTRACTS AS-IS
      - unlock.ts (174 lines) — already pure. unlockSentence(id, kind, slice) + predText, type-only imports, unit test in unlock.test.ts. Move verbatim.
      - script-editor/doc-preview.ts (102 lines) — already pure and already shared by both probes. buildDocPreviewHtml returns {html, width, minHeight, kindUsed, fallback}. Only injectEditorFonts touches the DOM (one document.head append). Move it to the shared directory and keep both import sites.

      EXTRACTS AFTER ONE CUT: RENDER vs MOUNT
      preview.ts's renderers (detailPanel, showFact, showDocument, showHypothesis, showQuestion, fallbackJson) read only CompileResult. They are impure only because each one ends by assigning host.innerHTML and titleEl.textContent. Change each to return {title, html} and the whole family becomes pure functions of (id, CompileResult). Each lens then owns the mount. That single change also makes them testable — preview.ts has zero tests today, while unlock.ts has a unit test and doc-preview.ts has one smoke test.

      CANVAS COUPLING — ONE CALLBACK, NOTHING ELSE
      preview.ts imports nothing from main.ts. All coupling arrives through PreviewDeps.
      - onJump(id) is the only canvas-flavored dependency. It fires from a [data-fact-id] click inside the document iframe. Canvas passes select + camera.centerOn; the script lens's own copy passes lens.jumpToHeading('Fact', id); a playtest lens passes its own "open that fact" or a no-op.
      - titleEl is a side effect, not coupling — return the title string instead.
      - getResult() is a deferred closure because result is assigned by the first rebuild. Under the SB-078 MobX spine this can read model.state.result directly.
      - NodeKind is imported from graph.ts, so the renderers drag in the canvas graph module for a 10-member string union. Move the union into the shared module and have graph.ts import it, not the reverse.

      STAYS BEHIND (OR MOVES WITH A PARAMETER)
      - wireDocFrame's fit math assumes a narrow rail: scale = min(1, wrap.clientWidth / width), and it writes wrap.style.height. A playtest surface showing a document at reading size does not want the downscale. Share it with the scale policy as an argument (rail vs full), or leave it per-lens.
      - The lightbox (open/close, backdrop click, window Escape listener) is a page-level singleton bound at init, not a renderer. Shareable, but it belongs in its own module beside the renderers.
      - Four copies of the same escape helper exist: kinds.ts escapeHtml, preview.ts esc, jump.ts esc, script-editor/main.ts esc. One belongs in the shared module.

      THE CSS IS THE REAL COST, AND IT IS ALREADY DRIFTING
      - Every preview rule is id-scoped as `#preview .funn-card`. A playtest host with any other id inherits nothing. Re-scope to a class at extraction time.
      - 14 preview rules exist in both index.html files. 10 are byte-identical. 4 have drifted on cosmetic values only: funn-quote font-size 19px vs 21px, node-card padding, node-json margin-top, .empty padding. A third copy makes it a three-way drift.
      - The token layer already agrees: all 27 tokens common to the two :root blocks are identical. Script-editor carries 16 extra (paper/ink/hint-* families), canvas one extra (--teal). A shared token stylesheet is safe to lift now; the extras stay per-page.
      - The detail-panel family (.detail-panel, .dp-*, .surface-label, .frank-line) is canvas-only — SB-055's own additions. It moves wholesale with the renderers, no merge needed.

      THE GAP SB-061 MUST STILL BUILD
      show() renders a player surface for 4 of 10 node kinds: fact, document, hypothesis, question. tiltak, dispatch, clock, conversation, recipe and proposal all land in fallbackJson under a "no player-facing surface" label. day_script_beats has no NodeKind at all and reaches the preview only through the fallback pools. So "every emitted entity kind renders in its player surface" means writing 6 new renderers plus a beat surface. Extraction gives SB-061 the frame and 4 of the surfaces, not the milestone.

      SHELL NOTE FOR THE LENS ITSELF
      The lab has no router. Each probe is its own vite page under prototypes/, and the lens switcher is plain anchors in the topbar. Canvas already renders a dead "Playtest" tab next to a dead "Pacing" tab. A third lens is a third directory plus two anchors, not new infrastructure. tsconfig.app.json already includes prototypes/, so the new module typechecks with no config change.

      RECOMMENDED SHAPE (a finding, not a plan)
      prototypes/shared/ holding: unlock.ts (moved), doc-preview.ts (moved), surfaces.ts (the pure renderers returning {title, html}), doc-frame.ts (wireDocFrame + lightbox, scale policy as an argument), and surfaces.css re-scoped from #preview to a class. Each lens keeps its own mount and passes its own jump.
