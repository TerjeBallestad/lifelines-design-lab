Question: ruling 1b (SB-022) ratified `# Proposal: f_a + f_b` with a Line: field — pair in the header, 24 blocks. The shipped frank_proposals do not fit that shape: relevant_fact_ids has arity 1, 2 and 3, several proposals key on relevant_categories instead of facts, each carries a handbok_id slug, and a global order integer ranks them. A pair header cannot express any of that. Ratify the real syntax — suggestion to react to: slug header `# Proposal: matlevering` + `Relevant: f_ingen_matkjop, f_dor_glott` and/or `Categories: Risiko` + `Line: «…»`, order = file order.

Least build: none — this is a board ruling. The 24 shipped proposals in tiny_olsen_slice.json are the test corpus.

How to start: pm get SB-022 (ruling 1b), then the frank_proposals section of ../lifelines-core-loop/resources/cases/olsen/source/tiny_olsen_slice.json.

Answer feeds: the follow-up compiler ticket (proposal emit) and SB-024's back-port of frank_proposals.
