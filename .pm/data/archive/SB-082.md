## Task
Cut the seam SB-060 found. Move the surface renderers out of the canvas probe into a shared module that the canvas rail, the script lens and the coming Playtest lens all import.

Scope, per the SB-060 resolution:
1. Split render from mount. preview.ts's detailPanel / showFact / showDocument / showHypothesis / showQuestion / fallbackJson return `{title, template}` where `template` is a lit-html `TemplateResult`, instead of writing host.innerHTML and titleEl.textContent. Each lens owns its own mount and calls `render(template, host)`.
2. Move unlock.ts and script-editor/doc-preview.ts into the shared module verbatim. Both are already pure.
3. Move the NodeKind union out of canvas/graph.ts into the shared module; graph.ts imports it.
4. Share wireDocFrame with the scale policy as an argument (rail vs full), and put the lightbox in its own module. The rail's `scale = min(1, wrap.clientWidth / width)` must not be baked in.
5. Re-scope the CSS from `#preview .x` to a class, lift the shared `:root` tokens (all 27 common tokens already agree), and reconcile the 4 drifted rules: funn-quote font-size 19 vs 21px, node-card padding, node-json margin-top, .empty padding.
6. Delete the third copy: script-editor/main.ts renderFactCard / renderDocPreview / wireDocFrame / openLightbox now import the shared module. Keep the script lens's own extras (funn-meta, fc-rel, chips, feeds-head) at its call site.
7. Drop the escape helpers from the renderers. lit escapes interpolations by construction, so `esc` disappears from preview.ts. The remaining copies (kinds.ts escapeHtml, jump.ts esc, script-editor/main.ts esc) belong to string-building code outside this seam — leave them until their own panels move to lit.

## Templating ruling (Terje, 2026-08-09)
lit-html, not LitElement, and no Tailwind.
- lit-html is already the panel idiom after SB-079 (inspector, worklist, status bar, menus). preview.ts is the last string-concatenation panel in the rail, so this change makes it consistent rather than introducing a pattern.
- lit's DOM diff is a functional win here, not only a style one: today a recompile assigns host.innerHTML, which destroys the document iframe and forces a reload plus a full re-run of wireDocFrame's fit/scale. Under lit the iframe element survives the re-render.
- LitElement and shadow DOM are out. Shadow roots block the shared `:root` token layer that both probes already agree on (27 of 27 common tokens identical).
- Tailwind is out for the probes. The doc surface lives inside an iframe Tailwind cannot reach, whose CSS is the Godot texture source. The card CSS is a deliberate mirror of hand_card.tscn and canvas_detail_panel.gd and must stay diffable against Godot. A shared class-scoped stylesheet already fixes the duplication.

## Done when
Both existing lenses look and behave exactly as they do now, the shared renderers have unit tests (they return TemplateResults, so they are testable for the first time), and the suite is green.
